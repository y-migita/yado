# Bun非依存の単一バイナリを配布の基本にする

利用者からBun要件を消すため、`bun build --compile`で作ったランタイム同梱の単一バイナリ(darwin arm64 / x64)をGitHub Releasesに置く。人間は`scripts/install.sh`で`~/.local/bin/yado`へ導入する。スキル同梱のシムは、Bunがあればそれを使い、なければ初回にReleasesからバイナリを自動取得して実行するため、エージェント経由の利用でもBunは不要になる。Bunが要るのは、このリポジトリ自体を開発する場合だけ。

Node移植も検討したが、WebSocketサーバーに`ws`などの依存が復活し、プロキシとデーモンの中核を書き直すことになるため退けた。コンパイル方式ならコードはBunのままで済む。コンパイル版は`Bun.main`が`/$bunfs/`配下になることで自身を検出し、デーモンを自分自身の`daemon run`サブコマンドとして起動する。
